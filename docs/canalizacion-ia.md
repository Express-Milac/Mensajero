# Canalización futura de IA

Gemini no forma parte de la ruta crítica de captura. Primero se conserva evidencia; después se interpreta.

La IA recibirá mensajes ya normalizados y autorizados, con contexto incremental por grupo. Cada evento generado deberá conservar enlaces N:M hacia los mensajes fuente para permitir revisión humana.

Si Gemini falla, la evidencia original permanece disponible y el trabajo puede reintentarse. No se enviarán chats no autorizados ni pegatinas descartadas.

Este hito permanece pendiente hasta estabilizar captura, multimedia y consulta de mensajes originales.
