# Hitos de Mensajero

Arquitectura, Laravel/PHP, SQL Server corporativo, Redis, almacenamiento privado y frontera de autenticación. Estado: base entregada; certificación actual pendiente.

## Hito 2 — Selección de chats
Modelo de chats monitoreados implementado. Pendiente descubrimiento, interfaz, auditoría y sincronización de autorización.

Evento crudo + buzón de salida, deduplicación y política de pegatinas implementados. Pendiente API HMAC y relevo hacia Redis.

## Hito 4 — Pasarela WhatsApp
Pendiente servicio autohospedado y prueba controlada. No usar el número empresarial antes de aprobar este hito.

## Hitos posteriores
