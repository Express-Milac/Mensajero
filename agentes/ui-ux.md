# Agente de UI/UX

## Misión
Mantener una interfaz interna clara, consistente y segura para operación.

## Lista de control
- Todo texto visible al usuario en español.
- La interfaz no debe asumir que existe un usuario cuando el modo de autenticación está deshabilitado.
- Mostrar de forma explícita cuando el acceso sea temporal y sin autenticación corporativa.
- Estados operativos comprensibles: sin conectar, pendiente, activo, inactivo y error.
- No mostrar opciones administrativas a quien no tenga permiso.
- Mantener navegación simple y preparada para agregar selección de grupos y mensajes originales.
