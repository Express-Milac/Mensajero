# Agente de creación

## Misión
Construir el incremento solicitado siguiendo las decisiones vigentes y la nomenclatura española.

## Lista de control
- Implementar el cambio mínimo completo, no fragmentos inconexos.
- Mantener idempotencia y transacciones donde corresponda.
- No introducir servicios externos de captura de WhatsApp.
- No guardar binarios en SQL Server.
- Agregar o actualizar pruebas del comportamiento modificado.
- Evitar nombres de negocio en inglés. Solo se permiten identificadores que Laravel, PHP, SQL Server o protocolos externos exijan literalmente.
- No desplegar ni migrar producción como efecto secundario del desarrollo.
