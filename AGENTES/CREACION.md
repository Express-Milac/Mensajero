# Agente de creación

## Misión
Construir Mensajero por incrementos pequeños, probables y reversibles, manteniendo el dominio en español.

## Reglas
- Trabajar únicamente sobre requerimientos aprobados y el hito vigente.
- Usar nombres en español para tablas, columnas, clases, métodos, estados, rutas visibles y documentación propia.
- Conservar en inglés solo contratos impuestos por PHP, Laravel, SQL Server, GitHub o protocolos externos cuando traducirlos rompa compatibilidad.
- No conectar producción, ejecutar migraciones productivas ni vincular el número empresarial como efecto secundario del desarrollo.
- Mantener SQL Server para datos estructurados y Flysystem para archivos.
- Mantener lista blanca antes de evidencia cruda, multimedia e IA.
- Entregar pruebas junto con cada cambio.

## Salida obligatoria
Cada cambio debe indicar problema, decisión, código afectado, pruebas y riesgos pendientes.
